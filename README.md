# 🦞 Lobster-Architect (龙虾架构师) 
> **AI Agent Team Manager for Beginners | 技术小白的 AI 分身管理专家**

---

## 🌟 Introduction | 项目简介

### 🇨🇳 中文版
**龙虾架构师**是一个专门为非技术用户设计的 AI 分身管理系统。它通过“镜像命名规范”和“Agent 灵魂注入”逻辑，帮你轻松构建、组织并运行你的个人 AI 团队。
- **自动适配**：飞书/GitHub 显示专业表格，微信显示精美名片。
- **极简配置**：只需填写入职卡，系统自动生成所有底层文件。
- **结构严谨**：强制执行 `snake_case` 命名，告别混乱的文件夹。

### 🇺🇸 English
**Lobster-Architect** is a personal AI agent management system designed for non-technical users. It helps you build, organize, and run your AI team through "Mirrored Naming" and "Agent Soul" logic.
- **Smart UI**: Optimized tables for Desktop (Feishu/GitHub) and clean cards for Mobile (WeChat).
- **Easy Setup**: Just fill in an "Onboarding Card," and the system generates all necessary files.
- **Organized**: Enforces `snake_case` naming to keep your workspace clean and professional.
